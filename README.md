## Featured Projects

### [Persian Response Ranking (Thesis)](https://github.com/bahar-shafieian)

Response ranking for Persian social-commerce conversations — a comparative study of lexical, semantic, and LLM-based rerankers, with a focus on evaluation bias and retrieval-conditioned fine-tuning.

- Built a 2,116-pair benchmark across three negative-sampling difficulty strategies (random / domain / lexically-confusable)
- Diagnosed severe position bias in LLM listwise ranking and corrected it with a shuffle-and-aggregate evaluation protocol (Permutation Self-Consistency)
- Found a method-invariant performance ceiling shared across six independent method families (lexical, dense-retrieval, prompting, fine-tuning, retrieval-augmented)
- Broke that ceiling with retrieval-conditioned LoRA fine-tuning (RAG-augmented SFT), generalizing across three model architectures (Gemma-2-9B, Llama-3.1-8B, Dorna2-8B) with gains of +0.07 to +0.13 Hits@1
- Ran a complementarity analysis across the three fine-tuned models and built a statistically validated confidence-routed ensemble that improved on the best single model

`Python` `PyTorch` `Transformers` `PEFT/LoRA` `TRL` `Sentence-Transformers` `BGE-m3` `pandas` `Google Colab`
